# 🐻 Spam

L'appli pour mettre le bazar pendant vos soirées en vocal : envoyer des mèmes, GIF et vidéos sur l'écran des potes, écouter la radio du salon ensemble, jouer des sons de la Soundbox, et lancer des quiz (QCM et Enchère arbitrée par une IA).

## ⬇️ Télécharger

Va dans **[Releases](../../releases/latest)** et prends le fichier qui correspond à ton ordi :

| Ordi | Fichier |
|---|---|
| 🍎 Mac (Apple Silicon et Intel) | `Spam-…-Mac.dmg` |
| 🪟 Windows (64 bits) | `Spam-…-Windows.exe` |

## 🍎 Installer sur Mac

1. Ouvre le fichier `.dmg` et **glisse Spam dans le dossier Applications**.
2. Lance Spam. La première fois, macOS dit qu'il ne peut pas l'ouvrir (l'appli n'est pas signée par Apple, c'est normal pour une appli entre potes).
3. Va dans **Réglages Système → Confidentialité et sécurité**, descends en bas et clique sur **« Ouvrir quand même »**.
4. Si macOS dit que l'appli est **« endommagée »**, ouvre le **Terminal** et tape cette ligne, puis relance Spam :

   ```
   xattr -cr /Applications/Spam.app
   ```

## 🪟 Installer sur Windows

1. Double-clique sur le fichier `.exe` : Spam s'installe tout seul (raccourci sur le bureau).
2. Si Windows affiche **« Windows a protégé votre ordinateur »**, clique sur **« Informations complémentaires »** puis **« Exécuter quand même »**.
3. Si ton antivirus râle, autorise Spam (l'appli n'est pas signée, c'est pour ça).

## 🚀 Premier lancement

1. Choisis ton **pseudo**.
2. Entre **le code du salon** que t'a donné l'organisateur : tout le monde doit avoir **exactement le même code**.
3. Mets une photo de profil dans **⚙ Réglages** (facultatif, mais c'est plus drôle).

## 🛟 Bon à savoir

- **Échap** ferme tout ce qui s'affiche sur ton écran.
- **🌙 Ne pas déranger** (dans les Réglages) : tu ne reçois plus rien.
- Tu peux régler le **volume des médias que tu reçois** dans les Réglages.
- Sur Windows, pour voir les mèmes par-dessus un jeu, mets le jeu en **« fenêtré sans bordure »** (en plein écran exclusif, le jeu passe par-dessus Spam).
