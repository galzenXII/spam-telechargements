Installer Spam

  1. Ouvre le fichier .dmg téléchargé et glisse Spam dans le dossier Applications.
  2. Lance Spam. La première fois, macOS refuse de l'ouvrir : l'appli n'est pas signée par Apple, c'est normal pour une appli entre potes.
  3. Va dans Réglages Système → Confidentialité et sécurité, descends en bas et clique sur « Ouvrir quand même ».
  4. Si macOS dit que l'appli est « endommagée », ouvre le Terminal, tape cette ligne puis relance Spam :
    xattr -cr /Applications/Spam.app
  1. Double-clique sur le fichier .exe téléchargé : Spam s'installe tout seul, avec un raccourci sur le bureau.
  2. Si Windows affiche « Windows a protégé votre ordinateur », clique sur « Informations complémentaires » puis « Exécuter quand même ».
  3. Si ton antivirus se méfie, autorise Spam : l'appli n'est pas signée, c'est pour ça.
  4. Ensuite, Spam se met à jour tout seul : un bouton vert « Redémarrer » apparaît quand une nouvelle version est prête.
🎩Fedorafichier .rpm 🏔Arch Linuxpaquet .pacman 📦AppImagetous les Linux · mises à jour auto
  1. Fedora : télécharge le .rpm, puis dans un terminal (dans le dossier Téléchargements) :
    sudo dnf install ./Spam-…-Linux.rpm
    Spam apparaît ensuite dans le menu des applications.
  2. Arch Linux : télécharge le .pacman, puis :
    sudo pacman -U Spam-…-Linux-Arch.pacman
  3. N'importe quel Linux : télécharge l'AppImage, rends-la exécutable puis lance-la (c'est la seule version Linux qui se met à jour toute seule) :
    chmod +x Spam-…-Linux.AppImage && ./Spam-…-Linux.AppImage
    Si elle refuse de démarrer, installe FUSE : sudo dnf install fuse-libs (Fedora) ou sudo pacman -S fuse2 (Arch).
  4. Wayland (Fedora par défaut) : Spam passe tout seul en mode compatible (XWayland) pour que les mèmes s'affichent par-dessus tes fenêtres. Si ça coince, préviens l'organisateur.
